# all@Ben-Recoil ⚡

**Standalone Precision Recoil Engine & AI Vision Detector for PUBG**  
*พัฒนาโดย all@Ben (Benjamin Daylight)*

ระบบคุมแรงดีดระดับพรีเมียมแบบ **Standalone 100% (ไม่ต้องพึ่ง Logitech G Hub)** พร้อมระบบ AI ตรวจจับปืน ของแต่ง ลำกล้อง ผ่านหน้ากระเป๋า (Tab) ใน PUBG และปรับชดเชยแรงดีดออโต้

---

## จุดเด่นสำคัญ (Key Features)

- **⚡ Standalone 100% ไม่ต้องติดตั้ง G Hub:**
  - ทำงานอิสระด้วย C# .NET 10 High-Precision Multimedia Timer (`timeBeginPeriod(1)`) ละเอียดระดับ 1ms
  - ใช้งานได้กับ **เมาส์ทุกยี่ห้อในโลก** (Logitech, Razer, Zowie, Pulsar, Lamzu, VGN, เมาส์ออฟฟิศ ฯลฯ)
  - หมดปัญหาโปรไฟล์ G Hub หลุด, สคริปต์ไม่โหลด หรือบั๊ก NumLock ค้าง
- **🎯 เลเซอร์เคิร์ฟ Monotonic (v8 Laser Engine):**
  - กราฟแรงดึงสมูท ไม่สะบัด ไม่หยัก คุมนิ่งสนิทเหมือนเลเซอร์
  - รองรับ Sub-pixel Float Accumulation (เก็บเศษพิกเซล 0.25px / 0.5px ไม่ทิ้งค่า)
- **👁 AI Vision ตรวจจับกระเป๋า (Tab Key Release):**
  - ดักจับการเปิด/ปิดกระเป๋าในเกม PUBG เมื่อปล่อยปุ่ม `Tab`
  - วิเคราะห์ภาพด้วย 64-bit dHash + Color Variance
  - ตรวจจับปืนช่อง 1 & 2, ปลอกลดแสง/คอมเพน, กริป, พานท้าย, สโคป (RedDot, 2x, 3x, 4x, 6x)
  - คำนวณตัวคูณแรงดีดและปรับค่า Base ให้ทันทีแบบเรียลไทม์
- **🛡 ระบบความปลอดภัย Desktop (Require ADS):**
  - ดึงเมาส์เฉพาะตอนกด **คลิกขวาเล็ง (ADS) ค้างไว้ + ยิงคลิกซ้าย**
  - คลิกซ้ายธรรมดาบน Windows / Desktop / เปิดกระเป๋า เมาส์จะไม่ถูกดึง ปลอดภัย 100%
- **🎲 Humanize Micro-Jitter:**
  - สุ่มการเคลื่อนไหวระดับเสี้ยวพิกเซลเลียนแบบการคอนโทรลของมือโปร ไม่แข็งเป็นหุ่นยนต์
- **🖥 จอยืดอัตโนมัติ (1728×1080 Borderless):**
  - ปรับความละเอียด Windows เป็น 1728×1080 เมื่อเปิด PUBG และคืนค่าจอเดิมเมื่อปิดเกม
- **📊 OSD HUD Overlay:**
  - ป้ายแสดงผลโปร่งใสบนมุมจอเกม (ซ้ายบน/ขวาบน) บอกสถานะ ON/OFF, ปืนที่เลือก, ค่า Base/X

## ปุ่มลัด (Hotkeys)

| ปุ่ม | การทำงาน |
|---|---|
| **\`** *(ข้างเลข 1)* | เปิด / ปิด มาโคร (Toggle ON/OFF) |
| **1** / **2** / **3** | สลับปืนช่อง 1, ช่อง 2, ช่อง 3 |
| **ลูกกลิ้งเมาส์** | สลับไปมาระหว่างปืนช่อง 1 ↔ 2 |
| **F7** | บังคับให้ AI สแกนหน้าจอกระเป๋าทันที |
| **F9** | วนเปลี่ยนโปรไฟล์พรีเซ็ต (M416, Beryl, AUG/ACE32) |
| **Tab** *(ใน PUBG)* | สแกนช่องกระเป๋าและคำนวณของแต่งให้อัตโนมัติ |

## วิธีสร้างโปรแกรม (Build & Run)

ต้องมี **.NET 10 SDK** ติดตั้งในเครื่อง (`winget install Microsoft.DotNet.SDK.10`)

1. ดับเบิลคลิกหรือรันคำสั่ง:
   ```powershell
   powershell -ExecutionPolicy Bypass -File build.ps1
   ```
2. จะได้ไฟล์ `AllBen-Recoil.exe` พร้อมรันได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมอื่นเสริม
